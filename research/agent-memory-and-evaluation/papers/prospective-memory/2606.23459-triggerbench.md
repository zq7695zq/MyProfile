# TriggerBench: Investigating Prospective Memory for Large Language Models

- **原文**：https://arxiv.org/abs/2606.23459
- **PDF**：https://arxiv.org/pdf/2606.23459
- **HTML**：https://arxiv.org/html/2606.23459

## 研究问题

传统记忆 benchmark 多在用户明确提问时测 retrospective memory。Agent 能否在没有显式提醒的情况下，主动想起一个延迟意图并在正确时机行动？

## Benchmark 设计

TriggerBench 将 prospective memory 场景与匹配的 retrospective-memory 对照结合，并设置正负对照和 overloaded triggers，用于测量：
- 主动回忆与触发准确性
- 误提醒 / false-alarm rate
- 多个请求并发时的注意力鲁棒性
- 长上下文下的前瞻记忆能力

## 关键发现

论文报告前瞻记忆比回顾性记忆更困难；随着上下文变长，PM 表现下降明显，而 RM 在相同设置中可保持较高表现。更强推理能提升主动召回，但也可能导致“总是提醒”的启发式，从而增加误报。

## 对工程 Agent 的启发

不要只统计“提醒了多少次”或“有没有提醒”。需要同时测 precision、recall、false-positive、trigger timing 和是否打断用户。一个永远主动提醒的 Agent 并不是好的 proactive Agent。
