# ProMemAgent: Long-Horizon Proactive Assistance with Context-Aware Prospective Memory from Sensory Perceptions

- **原文**：https://arxiv.org/abs/2610.27400
- **PDF**：https://arxiv.org/pdf/2610.27400
- **HTML**：https://arxiv.org/html/2610.27400v1

## 研究问题

一个人今天说“燕麦奶快喝完了”，但只有几天后路过超市才适合提醒。Agent 如何把过去的意图与未来的行动机会连接起来？

## 核心架构

1. 从日常多模态感知（如 wearable / mobile video、audio）中提取事件。
2. 将历史组织成 context-aware memory。
3. 生成 event-based 和 time-based prospective cues，并连接早期事件与后续发展。
4. 当前场景出现时，通过 cue-triggered retrieval 找回相关历史。
5. 使用 memory-augmented reasoner 判断此时是否真的需要帮助。

## Benchmark 与结果

论文提出 CPMBench：1,000 个实例、八类日常场景；比较 19 个 proactive agent、full-context LLM、RAG 和 memory baseline。摘要报告 ProMemAgent 在长周期主动协助上超过最强 baseline；正文报告 F1 高出 9.7 个百分点。

## 局限与风险

这是预印本和 benchmark 研究，不等于已证明全天候真实部署可靠。连续视频/音频感知涉及隐私、数据最小化、错误关联和误提醒风险；这些问题不能由 benchmark 分数自动解决。
