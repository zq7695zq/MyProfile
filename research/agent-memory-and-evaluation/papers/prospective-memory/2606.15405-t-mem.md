# T-Mem: Memory That Anticipates, Not Archives

- **原文**：https://arxiv.org/abs/2606.15405
- **PDF**：https://arxiv.org/pdf/2606.15405
- **HTML**：https://arxiv.org/html/2606.15405

## 研究问题

传统长期记忆常靠 query 与历史文本的相似度检索。如果未来问题与历史记录没有相同词语或实体，但两者在语义上相关，记忆还能否被找回来？

## 核心方法

T-Mem 在写入记忆时就预演未来可能出现的检索情境，生成 write-time triggers。论文把记忆分为单条事实和完整对话两种粒度，并同时构建描述性与关联性触发线索。

## 关键结果

论文报告在 LoCoMo 与 LoCoMo-Plus 上达到当时的最佳表现，重点改善表面词汇不相似、但语义链条相关的记忆召回。

## 与 ProMemAgent 的区别

T-Mem 主要解决“将来有查询时，如何让相关记忆可被召回”；ProMemAgent 进一步尝试利用当前感知场景触发此前延迟意图，决定是否主动提供帮助。前者的 trigger 不能自动等同于完整的主动行动策略。

## 对工程 Agent 的启发

写入 Jira / PR 记忆时，不只记录“修复了什么”，也记录未来什么现象、报错、文件变更或用户需求可能使这条经验再次相关。
