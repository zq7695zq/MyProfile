# Continual Learning Bench: Evaluating Frontier AI Systems in Real-World Stateful Environments

- **原文**：https://arxiv.org/abs/2606.05661
- **PDF**：https://arxiv.org/pdf/2606.05661
- **HTML**：https://arxiv.org/html/2606.05661

## 研究问题

Agent 是否真的能从连续任务中学到环境特定知识，并在后续任务上变得更好？还是只是在重复调用更强的基础模型？

## Benchmark 设计

CL-Bench 跨六个领域设计连续任务序列，包括软件工程、信号处理、疾病预测、数据库查询、策略游戏和需求预测。任务中包含预训练模型无法事先知道的潜在结构，并可能在中途发生 concept drift。

论文引入 gain 指标，比较有历史经验的 stateful agent 与从零开始的 stateless baseline，试图隔离“从经验学习”的增益。

## 关键发现

论文报告，在其测试系统中，naive in-context learning 有时优于专门的 memory 管理系统；当前记忆系统仍可能过拟合近期观察、不能跨任务复用知识，或不能及时修正过时知识。

## 局限

论文强调其系统覆盖和成本约束，不能把单次 benchmark 排名解释为所有记忆架构的普遍优劣。CL-Bench 也是一个新 benchmark，复现实验需要固定任务版本、模型和运行设置。

## 对工程 Agent 的启发

评估 Skill 不能只看单个 Jira 是否完成。应把同一仓库的 issue 按时间排序，比较 Agent 是否逐渐减少探索步骤、正确复用项目约定，并在代码结构变化后及时更新旧知识。
