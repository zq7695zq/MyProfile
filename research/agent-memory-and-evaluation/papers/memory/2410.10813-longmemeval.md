# LongMemEval: Benchmarking Chat Assistants on Long-Term Interactive Memory

- **原文**：https://arxiv.org/abs/2410.10813
- **PDF**：https://arxiv.org/pdf/2410.10813
- **HTML**：https://arxiv.org/html/2410.10813
- **版本**：v2（2025-03-04）

## 研究问题

如何评估对话助手在长期、多 session 互动中的记忆能力，而不是只看单轮检索？

## 五项能力

- 信息抽取
- 跨 session 推理
- 时间推理
- 知识更新
- 应当拒答 / 不确定时 abstain

## 方法与结果

LongMemEval 提供 500 个问题，嵌入可扩展的用户—助手历史对话中。论文将记忆系统拆为 indexing、retrieval、reading 三阶段，并研究 session 分解、事实增强索引和时间感知查询扩展等设计。论文报告：商业助手和长上下文模型在持续交互记忆上会出现明显准确率下降（摘要报告约 30%）。

## 局限

LongMemEval 主要测“给出问题后能否找回/推理历史”，并不直接测试 Agent 是否能在用户没有提问时主动判断“现在应该做什么”。

## 对工程 Agent 的启发

为 Skill / QA Agent 设计记忆评估时，不只测召回率；还要测时间更新、过时信息覆盖、跨 Jira/PR 关联，以及信息不足时是否会 abstain。
