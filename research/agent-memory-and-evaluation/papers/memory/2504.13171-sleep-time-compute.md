# Sleep-time Compute: Beyond Inference Scaling at Test-time

- **原文**：https://arxiv.org/abs/2504.13171
- **PDF**：https://arxiv.org/pdf/2504.13171
- **HTML**：https://arxiv.org/html/2504.13171

## 研究问题

对于已经存在、未来会被反复使用的上下文，为什么一定要等到用户发问时才做全部推理？

## 核心方法

在两次交互之间的 idle / sleep 时间，对已知上下文进行离线推理，提前生成可能对未来问题有帮助的结构化信息。用户真正提问时，把这些预计算结果带入 prompt，减少重复计算。

## 论文报告的结果

- 在 Stateful GSM-Symbolic 与 Stateful AIME 上，达到相同准确率所需的 test-time compute 可减少约 5 倍。
- 增加 sleep-time compute 后，特定实验设置中的准确率还能继续提升。
- 对同一 context 的多个相关问题摊销预计算成本，平均每问成本可下降约 2.5 倍。
- 论文还包含一个 agentic SWE 场景案例。

## 局限

收益与未来 query 是否可预测有关。离线推理不是“无成本记忆”：它把成本从用户等待时转移到空闲时间，也可能预计算错误或过时信息。
