# Generative Agents: Interactive Simulacra of Human Behavior

- **原文**：https://arxiv.org/abs/2304.03442
- **PDF**：https://arxiv.org/pdf/2304.03442
- **HTML**：https://arxiv.org/html/2304.03442

## 研究问题

如何让一组 LLM Agent 在持续变化的环境中表现出连贯、可解释、能随经历变化的行为？

## 核心架构

论文提出三项关键机制：

1. **Memory stream**：把经历记录为自然语言事件。
2. **Reflection**：周期性地把具体经历归纳为更高层次的反思。
3. **Planning**：根据角色、记忆和当前环境生成日程，再根据新观察重新计划。

检索会综合相关性、近期性和重要性，不是简单按时间顺序拼接全部历史。

## 实验

作者在类似 The Sims 的小镇环境中部署 25 个 Agent，研究个体行为和群体层面的涌现行为，并通过消融分析观察 memory、reflection、planning 的作用。

## 局限

这是模拟社会环境中的行为可信度研究，不是面向真实软件工程的任务成功率评测；模拟行为的连贯性也不能直接证明真实世界的主动决策可靠。

## 对工程 Agent 的启发

把每次 Jira / PR 工作记录为事件；从多个事件归纳稳定的项目规则、常见故障模式和决策偏好；在新任务中按相关性召回这些反思，而不是把旧聊天记录原样重放。
