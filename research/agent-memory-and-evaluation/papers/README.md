# arXiv Paper Library

这里按主题整理本次调研引用的 arXiv 论文。**每篇论文都有独立阅读卡片**，包含原文、PDF、HTML、版本信息、研究问题、方法、结果、局限与工程启发。

> 重要：arXiv 的“可免费下载”不等于所有 PDF 都可由第三方重新托管。arXiv 明确要求：除非作者授权或该版本的 license 明确允许，否则不得把 e-print PDF / source 文件存储并从第三方服务器提供下载。因此本库默认保存原创阅读笔记、CC0 元数据和原文链接；只有许可核实允许的论文才可放 PDF 副本。见 [arXiv License Policy](https://info.arxiv.org/help/license/index.html) 和 [arXiv API Terms](https://info.arxiv.org/help/api/tou.html)。
